# 制作过程

## 目标

制作一个能用鼠标“捏住丝袜、向外拉离腿部、松手回弹”的浏览器项目。外形最终以提供的实际 3D 模型为准，支持材质切换，并使用提供的手部照片替代模型区域的箭头光标。

## 阶段一：先验证交互（2026-11-10）

最初通过腿部截面生成曲面，并在外层建立独立网格。射线选点确定抓取区域，拖动距离转成布料位移；以局部距离衰减生成连续拉起区域，再用弹簧阻尼恢复。这个版本验证了交互方向，但外形是程序化近似，无法满足参考图中的腿型要求。

## 阶段二：双腿与材质

加入双腿、脚部连续曲面和透肤 / 缎面 / 厚袜 / 渔网 / 蕾丝预设。渔网使用程序化透明孔洞；光泽、覆盖度和弹性参数随预设变化。

这仍然是外形近似：单张正面图没有侧面、背面和原始深度，不能据此保证无损还原真实三维模型。因此没有把图片效果或参数化模型当作最终原模。

## 阶段三：手部照片交互

提供的 WebP 自带透明通道，直接保留使用。CSS 叠加图片，指尖位置按图片宽度的 15.2%、高度的 21.1% 对齐到抓取点；拖动时通过被选中的布料顶点投影更新手的位置。

面板继续使用普通鼠标；照片手可关闭和调整大小。轻微旋转与缩放只是按下反馈，没有将单张照片伪装成可屈伸手指的三维模型。

## 阶段四：接入提供的真实模型

提供的 ZIP 包含一个 OBJ、一个 MTL 和四张 4096 × 4096 PBR 贴图。检查得到：

- OBJ 原始位置顶点 749,723；按位置 / UV 对拆分后，运行资源含 863,144 个顶点。
- 共 1,499,482 个三角面，所有面有 UV。
- 单个对象、单套材质，无 OBJ 法线记录；运行时重新计算法线。
- 原始纹理中已有丝袜纹路，未提供独立裸肤、袜层或骨骼。

模型准备工具把 OBJ 转成紧凑的索引几何，保留完整精度；用 meshoptimizer 创建 18 万面预览。从下肢表面提取并简化出 3.5 万面独立袜壳。原始文件不覆盖，运行时身体网格不变。

同时用模型的实际三角形和原始 UV / 颜色贴图进行 CPU 正面渲染，检查形状与贴图对齐。仓库中的预览图来自这一步，不是网页截图。

## 阶段五：处理“整体贴图”与换袜的冲突

整体贴图里的丝袜纹路不能当成真实裸肤。保留原始外观模式用于对照；切换丝袜时，着色器在袜层下面近似重建肤色，然后叠加新的袜类材质。拉伸区域增加透光，显示布料与静态身体之间的间隙。

这个办法让新材质与拉伸可以工作，但不能从有袜贴图恢复丢失的真实皮肤。要进一步提高质量，需要独立裸肤贴图、经过整理的衣物拓扑和更完整的碰撞模型。

## 发布整理（2026-11-11）

保留静态演示和全部运行资源，增加固定版本的开发依赖、离线单文件生成、几何 / 交互自动检查，以及运行和技术文档。没有把旧实验脚本、本机绝对路径、部署系统凭据或 `.openai` 站点配置放入发布目录。

## 哪些已经验证

实际几何、UV 与贴图的检查渲染；完整模型面数；简化后顶点来自原模型；局部拉伸不影响另一条腿；局部法线碰撞约束；回弹与重置；原身体网格不变；离线资源内嵌；手部光标的载入回退和状态切换。

浏览器自动操作曾因工具不能可靠识别当前地址而被中止，因此没有把数值检查当成 GPU 视觉验收。在线入口于 2026-11-11 直接请求返回 HTTP 200，最终浏览器画面仍需人工检查。
