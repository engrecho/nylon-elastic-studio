# v0.4.0 · 用户模型交互版

使用提供的真实 OBJ 模型，实现独立丝袜层的局部抓取、拉伸与阻尼回弹，支持照片手部光标及丝袜外观切换。

## 体验与下载

- [在线演示](https://nylon-elastic-studio-nov10.majorsnail16384.chatgpt.site/)
- `NYLON-offline.html`：单文件离线演示，直接用现代 Chrome / Edge 打开。
- `nylon-elastic-studio-v0.4.0.zip`：完整运行资源、脚本和说明；解压后运行 `npm start`。

## 内容

- 18 万面默认预览与完整 1,499,482 面原模。
- 从原模型表面提取的 35,000 面动态袜壳。
- 原始贴图、透肤、缎面、厚袜、渔网、蕾丝外观。
- 透明照片手部，抓取点跟随、大小和开关控制。
- 原模对照、旋转 / 缩放、自动演示和重置。
- 制作过程、技术文档、离线生成器与自动化检查。

## 验证与边界

几何与贴图检查渲染、顶点来源、局部捏持、对侧腿隔离、法线约束、回弹、重置、离线资源和手图检查已完成。在线入口 2026-11-11 直接请求返回 HTTP 200。

此版本以预览版发布：最终 GPU 着色器、浏览器画面和移动端触控尚未完成视觉验收。原包没有独立裸肤贴图，换袜肤色为近似重建；碰撞和布料为局部视觉近似，照片手不是三维骨骼手。
